# 일정 기획 규칙

질의 답변(장소·동행·코스·국내/해외·이동수단·날짜)으로 추천안을 만들고 일정에 반영하는 규칙입니다.

## 0. 추천 보기를 고르는 기준 (질의 단계)
보기는 아래 신호를 조합해 만들고, 추천 이유를 description에 한 줄로 적는다.
- **시기**: 오늘 날짜 기준 출발 시점의 계절·날씨(장마·태풍·폭설), 축제·단풍·벚꽃 시기, 공휴일·연휴(붐빔·가격 상승).
- **동행**: 1절 페이스표. 부모님 → 평지·짧은 이동·온천/정원/역사, 아이 → 체험·동물원·수족관, 연인 → 야경·카페, 친구 → 먹거리·야시장·액티비티.
- **기간**: 당일·1박은 이동 2시간 이내 지역, 2박 이상은 거점 1~2곳, 4박 이상만 거점 3곳.
- **이동수단**: 렌터카 없음 → 역·터미널 중심 지역/동선, 렌터카 → 외곽 명소 포함.
- **이미 고른 것**: 장소가 정해졌으면 숙소·경로안은 그 동선 안에서만.
- 확신이 낮으면 보기를 서로 성격이 다르게(예: 도시/자연/바다) 만들어 사용자가 방향을 고르게 한다.
- 추천은 웹 검색으로 사실(운영 여부·휴무·계절 행사 일정)을 확인한 뒤에 제시한다.

## 1. 동행(관계)별 페이스

| 동행 | 하루 주요 장소 | 이동 1회 상한 | 꼭 넣을 것 |
|---|---|---|---|
| 부모님·어르신 | 2~3곳 | 1시간 30분 | 오후 휴식 1시간, 계단·오르막 적은 동선, 화장실 위치, 이른 저녁(18시 전후), 앱 큰 글씨 그대로 |
| 영유아(0~6세) | 2곳 | 1시간 | 낮잠 시간 비우기, 유아차 가능 여부, 수유실, 아이 메뉴 가능한 식당 |
| 어린이(7~12세) | 3곳 | 2시간 | 체험형 장소 1곳 이상, 간식 시간 |
| 연인·배우자 | 3~4곳 | 2시간 | 저녁 분위기 좋은 식당 1곳 예약 후보, 야경/일몰 시간 |
| 친구 | 4~5곳 | 2시간 30분 | 저녁 이후 일정(야시장·바), 비용 나눔 메모 |
| 혼자 | 4~5곳 | 3시간 | 혼밥 가능한 식당, 안전 메모(늦은 밤 이동) |

여러 유형이 섞이면 **가장 느린 사람 기준**으로 맞춥니다.

## 2. 국내 / 해외

**국내 (region: domestic)**
- 지도 링크: 네이버지도(자동). 길안내: 카카오맵(자동, car일 때).
- 주소 카드: 한국어 주소 + 전화만. 회화·환율 섹션 없음.
- 준비물: 신분증, 충전기, 상비약 + 이동수단별 항목.

**해외 (region: overseas)**
- 지도 링크: 구글지도(자동).
- 모든 숙소·주요 목적지에 `places`(현지어 이름·현지어 주소·전화) → 택시 주소 카드.
- `meta.addr_ask`에 현지어 "이 주소로 가 주세요".
- `info.phrases`: 인사, 감사, 이 주소로 가 주세요, 화장실 어디예요, 계산해 주세요, 알레르기(필요 시) — 6~10개.
- `info.sections`: 입국 서류(전자 입국 등록 여부·링크), 환율·결제(현금 비중, 교통카드), 콘센트 전압, 긴급번호(현지 경찰·구급, 대사관/영사관).
- 준비물 `before`: 여권 유효기간 6개월, 입국 등록, eSIM/로밍, 여행자보험, 환전.
- 첫날은 공항 도착 후 입국심사·수하물 시간(국제선 1시간)을 일정에 넣음. 마지막 날은 출발 2~3시간 전 공항 도착.

## 3. 이동수단별

| 수단 | 일정 반영 | 티켓/정보 | 준비물 |
|---|---|---|---|
| flight | 국내선 출발 1시간 전, 국제선 2시간 30분 전 공항 도착 이벤트 | 항공권 티켓 카드(편명·예약번호·수하물) | 신분증/여권 |
| train | 역 도착은 출발 15~20분 전 | 승차권 카드(열차번호·좌석) | 승차권 앱 |
| bus | 정류장 도착 10~15분 전, 고속/시외는 승차장 번호 | 승차권/QR 카드 | — |
| car | 렌터카 인수·반납 이벤트(반납 전 주유 30분), 장소마다 주차 정보를 `meta`에, 이동 시간은 교통량 고려 1.2배 | 렌터카 예약 카드, 보험·고객센터 연락처 | 운전면허증(해외는 국제운전면허증+국내면허증) |
| subway | 환승 1회 이내 동선 우선 | 교통카드 안내 | 교통카드 |
| taxi | 해외는 반드시 주소 카드 연결(`addr`) | 택시 앱 이름 | — |
| ship | 출항 30분 전 도착, 기상 결항 대안 | 승선권 카드 | 신분증 |
| walk/bike | 도보 20분 넘는 구간은 대안 교통 메모 | — | 편한 신발 |

## 4. 코스 → 일정 변환
1. 사용자가 준 코스 순서를 **유지**합니다. 순서를 바꾸면 이유를 말하고 확인받습니다.
2. 각 장소의 운영시간·휴무일을 **웹 검색으로 확인**하고, 여행 요일에 휴무면 경고 후 대안을 제시합니다.
3. 이동 시간은 지도 기준 실제 소요(검색)로, 확인 못 하면 `tip`에 "이동 시간 확인 필요".
4. 식사 줄(`meal`)은 하루 조식·중식·석식을 기본으로 둡니다. 정해진 식사는 그대로 확정, 아니면 끼니마다 **동선 근처 2곳**(앞뒤 일정 장소에서 걸어서 10~15분 이내, 그 시간 영업, 먹거리 제한 반영)을 `meals`에 넣고 질의 또는 앱에서 고르게 합니다. 각 후보에 `near`(어디서 얼마나), `hours`, `price`, `why`(추천 이유)를 채웁니다.
5. 숙소 체크인/체크아웃, 짐 보관을 빠뜨리지 않습니다.
6. 날씨: 여행이 16일 이내면 예보 검색 결과, 아니면 해당 월 평균 기온을 `weather.text`에 "평년"으로 표기.

## 5. 확인할 수 없는 정보
- 예약번호·좌석·편명 등 사용자가 주지 않은 값은 **지어내지 않습니다.** 빈칸 대신 `tip: "예약 후 입력"`.
- 검색으로 확인한 운영시간은 `meta`에 "(2026-10 확인)"처럼 확인 시점을 붙입니다.
